# AI Features — OnePlace

OnePlace integrates a suite of AI-powered features built on top of the Groq inference API (using the **LLaMA 3.3 70B** language model) and the HuggingFace **sentence-transformers** embedding model. These features are designed to assist both community creators and members, covering content generation, personalised learning support, community management, and intelligent search.

## Feature Descriptions

### 1. AI Study Buddy
**Location:** Classroom → Lesson view (Quiz me button)

When a member opens a lesson, they can click **Quiz me** to generate a personalised 5-question multiple-choice quiz based on that lesson's content. The system first attempts to fetch the YouTube captions of the lesson video. If none are available, it downloads the video audio and transcribes it using **Groq Whisper** (a speech-to-text model). The resulting transcript is cached in the database so future quiz requests are instant. If no video or transcript exists, the quiz falls back to the lesson title. The quiz is generated by the LLaMA model and includes correct answers and explanations for each question.

**Technical flow:**
1. Member clicks Quiz me on a lesson
2. Backend checks if a transcript is already cached
3. If not: fetches YouTube captions or transcribes video audio via Whisper
4. Transcript is saved to the database for future use
5. LLaMA generates 5 MCQ questions from the transcript/content
6. Quiz is displayed in an interactive modal with instant feedback

---

### 2. Progress Coach
**Location:** Classroom → Course page (dismissible banner)

When a member opens a course page and has been inactive for 2 or more days (i.e. has not completed a lesson recently), a personalised motivational banner appears at the top of the page. The AI reads the member's progress data — their name, the number of days since their last completed lesson, the name of that lesson and course, and their overall completion count — and writes a short warm message encouraging them to continue. The banner can be dismissed and is not shown to members who are actively progressing.

**Technical flow:**
1. Page loads and queries the member's last lesson completion date
2. If inactive for 2+ days (or never started), the backend calls LLaMA with progress context
3. LLaMA generates a 2–3 sentence personalised catch-up message
4. Banner is displayed; disappears when dismissed or on the next visit if active

---

### 3. Community Matchmaking
**Location:** Community sidebar → Recommended for you widget

Members who belong to one or more communities receive personalised community recommendations. The AI is given a description of the member's current communities and a list of up to 20 other public communities on the platform. It selects the 3 best matches based on interest overlap and returns a one-sentence reason for each recommendation.

**Technical flow:**
1. Backend fetches the member's active community memberships and their descriptions
2. Fetches up to 20 communities the member has not joined
3. LLaMA selects the top 3 matches and explains each recommendation
4. Results are displayed in the community sidebar

---

### 4. AI Q&A Bot
**Location:** Floating chat button on every community page

Each community has an embedded AI chat assistant that members can use to ask questions. The bot uses **Retrieval-Augmented Generation (RAG)**: rather than relying on the model's general knowledge, it searches the community's own content — posts, lesson transcripts, and knowledge base documents — to find relevant context and answer the question. The search is semantic (meaning-based, not keyword-based), using vector embeddings and cosine similarity to find the most relevant content. Conversation history is maintained within the session.

**Technical flow:**
1. Member types a question
2. The question is converted into a vector embedding (HuggingFace)
3. All community posts, lessons, and knowledge docs are compared by cosine similarity
4. The top matching content is injected into the LLaMA prompt as context
5. LLaMA answers the question using that context
6. The answer is returned and conversation history is preserved for follow-up questions

---

### 5. Smart Post Assistant
**Location:** Create post modal → toolbar (sparkles button)

When writing a post, members and creators can click the sparkles button in the editor toolbar to access three AI writing actions:
- **Improve wording** — rewrites the text for clarity and engagement while keeping the same ideas
- **Fix grammar** — corrects spelling, grammar, and punctuation without changing the meaning
- **Expand idea** — makes the text approximately twice as long with added detail and context

The AI rewrites the content in-place inside the editor.

### 6. Knowledge Base
**Location:** Settings → Knowledge Base tab

Creators can upload documents to build a custom knowledge base for their community's AI Q&A bot. This allows the bot to answer questions using information that is not contained in posts or lessons — such as FAQs, course syllabi, community rules, or any other reference material.

Creators can either paste text directly or upload a `.txt` or `.md` file. Each document is automatically embedded (converted to a vector) in the background so the Q&A bot can find it by meaning. Documents are listed with an **Indexed** badge once they are ready for use, or an **Indexing…** badge while embedding is in progress.

The tab also includes a **Reindex** button that regenerates embeddings for all community content (posts, lessons, and knowledge docs) at once — useful for backfilling content that existed before the embedding system was set up.

**Technical flow:**
1. Creator uploads a document or pastes text into the settings tab
2. Document is saved to the database
3. The backend generates a vector embedding for the document content (fire-and-forget, non-blocking)
4. When a member asks the Q&A bot a question, knowledge docs are searched alongside posts and lessons
5. Relevant document excerpts are included in the LLaMA context

### 7. Churn Prediction
**Location:** Settings → Analytics page

Creators can run an on-demand churn risk analysis for their community. The system calculates a risk score for each active member based on their engagement signals over the past 30 days: number of posts created, number of comments written, and whether their subscription is expiring within 7 days. Members with a medium or high risk score are listed, and LLaMA generates a plain-English summary of the overall churn situation with one actionable recommendation for the creator.

**Risk scoring:**
- No posts in 30 days: +40 points
- Fewer than 2 posts: +20 points
- No comments in 30 days: +30 points
- Fewer than 3 comments: +15 points
- Subscription expiring within 7 days: +30 points
- Score ≥ 70 → High risk | Score ≥ 40 → Medium risk

---

### 8. AI Analytics Summary
**Location:** Settings → Analytics page

Creators can generate a plain-English summary of their community's performance for the current month. The system aggregates key metrics — total and active members, new member growth compared to the previous month, revenue, posts, comments, and likes — and passes them to LLaMA, which writes a 3–4 sentence summary with a growth trend assessment and one actionable insight. A one-click CSV export of the raw data is also available.

---

### 9. Sentiment Analysis
**Location:** Settings → Analytics page

Creators can run an on-demand sentiment analysis of their community's posts from the last 30 days (up to 50 posts). LLaMA classifies the overall mood as positive, neutral, or negative, provides a percentage breakdown across the three categories, identifies the top recurring themes in the community's conversations, and writes a 2–3 sentence plain-English summary of the findings.

## Shared Infrastructure

### Embedding Model
All semantic search across the platform uses the **HuggingFace Inference API** with the `sentence-transformers/all-MiniLM-L6-v2` model, which produces 384-dimensional vector embeddings. These vectors are stored as float arrays in PostgreSQL and compared using cosine similarity at query time.

### Auto-Embedding on Save
Whenever a lesson is saved with a transcript, or a knowledge document is created, the backend automatically generates and stores an embedding in the background (fire-and-forget). This ensures new content is immediately searchable by the Q&A bot without any manual action.

### Transcript Generation
When a creator uploads a video lesson and checks **Generate transcript**, the system:
1. Attempts to fetch captions from YouTube (free, instant)
2. Falls back to downloading the video audio and transcribing it with **Groq Whisper** (AI speech-to-text)
3. Saves the transcript to the lesson so it is used by both the Study Buddy quiz and the Q&A bot

### Language Model
All text generation (quiz questions, coaching messages, recommendations, summaries, chat answers) uses **Groq's hosted LLaMA 3.3 70B Versatile** model via the Groq SDK. Groq's inference infrastructure provides low-latency responses suitable for real-time use cases.
